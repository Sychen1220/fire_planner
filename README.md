# 半 FIRE Planner

半 FIRE Planner 是一个本地运行的个人财务规划工具，用来回答：在当前资产、收入和生活支出下，选择不同退出时间，是否能够支持目标生活方式。

项目面向希望降低工作强度、逐步实现半退休的人群。用户可以录入生活预算、金融资产、退出前收入、一次性收入、退出后的主动收入和预期年化收益率，系统会按月预测资产变化，并比较多个退出方案。

## 功能

- 维护年度生活预算，支持月度、年度和一次性支出。
- 维护金融资产、非金融资产和负债信息。
- 按月预测资产变化，支持预期投资收益。
- 为每个退出方案单独设置退出月份、退出前月薪和多条一次性收入。
- 按需添加或删除退出方案和一次性收入记录。
- 在同一张图表中比较多个方案的资产曲线。
- 显示半 FIRE 目标资产和完全 FIRE 参考资产。
- 展示退出节点的年度可支配资金、年度缺口、覆盖率和可行性状态。
- 支持压力测试，包括 0% 收益、资产回撤、连续无主动收入和生活预算增加等情景。
- 使用 SQLite 在本地保存规划数据和历史结果。

## 计算口径

系统按月进行预测。每个月的资产计算为：

```text
月末资产 = 月初资产
         + 方案月薪
         + 当月一次性收入
         + 月初资产 × 预期年化收益率 ÷ 12
         - 当年生活预算 ÷ 12
```

退出月份的资产定义为该月收入和支出完成后的月末资产。退出月份之后，资产曲线继续延伸到用户设置的预测期末，并使用半 FIRE 后月收入进行预测。

退出节点的年度可支配资金为：

```text
年度可支配资金 = 半 FIRE 后主动收入 + 退出资产 × 预期年化收益率
年度缺口 = 年度生活预算 - 年度可支配资金
```

规划提款率只作为风险参考上限：

```text
风险参考上限 = 退出资产 × 规划提款率
完全 FIRE 参考资产 = 年度生活预算 ÷ 规划提款率
```

规划提款率不会重复计入年度可支配资金。金额在内部使用整数分和 `Decimal` 计算，以避免浮点误差。

## 快速开始

项目要求 Python 3.11 或更高版本。

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
streamlit run app.py
```

启动后打开 `http://localhost:8501/`，按侧边栏顺序填写：

1. 我的生活：录入年度生活预算。
2. 我的资产：录入金融资产及其他资产信息。
3. 开始测算：设置预测参数并添加退出方案。

## 产品边界

这是一个规划和比较工具，不构成投资建议。MVP 不提供自动交易、银行账户连接、税务规划、社保精算、房产估值或真实资产托管功能。
